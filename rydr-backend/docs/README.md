# Backend documentation

This directory keeps backend planning and historical audit material out of the
mobile-app source trees.

- `projects/` contains implementation briefs for backend-owned capabilities.
- `audits/` contains dated readiness reviews and completed-phase records. Audit
  findings describe the repository at the time they were written; paths are
  maintained so they continue to point at the consolidated backend tree.

Operational setup belongs beside the component it describes. Firebase-specific
guides therefore live in `../firebase/docs/`, and service-specific instructions
live in each service's README.
